# 수업 전 QA 체크리스트

## 학생

- [ ] 이름 + PIN 로그인
- [ ] 월드에서 1~12차시 카드와 잠금 상태 확인
- [ ] 1차시 위치·층·개수 문제
- [ ] 2차시 방향 문제에 `앞·뒤·왼쪽·오른쪽·위`만 표시되는지 확인
- [ ] 3차시 위·앞·옆 격자 그리기
- [ ] Builder 보관함 블록을 마우스와 터치로 끌어 놓기
- [ ] 보관함 탭 → 작업판 탭으로 놓기
- [ ] Ghost 색, 블록 위 스냅, Undo/Redo, 삭제
- [ ] 5차시 제한 시점에서 회전·보기 버튼이 잠기고 추가 정보 후 해제되는지 확인
- [ ] 오답 3회 후 힌트, 힌트 뒤 오답 후 정답 공개
- [ ] 더 풀어보기에서 새 seed 문제와 틀린 문제 다시 풀기
- [ ] 9차시 친구 문제 코드 생성·풀이
- [ ] 10~11차시 건축물 중간 저장·복원·소개서
- [ ] 12차시 종합 문제와 자기평가
- [ ] XP와 별의 의미, 보상 화면 확인

## 교사

- [ ] 교사 로그인과 학급 선택
- [ ] 학생 여러 명 미리보기·생성 및 PIN 확인
- [ ] 학생 링크 복사
- [ ] QR 배포 절차(현재는 링크 복사 후 별도 QR 도구 사용)
- [ ] 차시 전체/개별 잠금과 추가 문제 수 5·10·15·20
- [ ] 학생 진도·시도·힌트·정답 공개·3D 기록
- [ ] 3D 문제 제작 및 학생 화면 미리보기
- [ ] 수동 학습지 importer의 업로드·crop·검토·등록

## 기기

- [ ] Chrome/Whale/Edge, 1366×768 데스크톱
- [ ] 터치 Chromium, 1024×768 태블릿
- [ ] iPadOS Safari 가로·세로: 블록 drag, tap-to-place, 빈 공간 회전, pinch zoom
- [ ] orientation change 뒤 canvas 크기와 버튼이 잘리지 않음
- [ ] canvas 조작 중 페이지 스크롤이 발생하지 않음
- [ ] 저사양 기기에서 블록 이동과 회전이 끊기지 않음

## 자동 검증

```bash
npm run audit:problems
npm test
npm run test:security
npm run typecheck
npm run lint
npm run typecheck:edge
npm run build
npm run test:e2e
```

`test:e2e`가 실행 환경의 포트 바인딩 제한으로 시작되지 않으면 그 사실을 기록하고 실제 Mac·Chromium에서 다시 확인합니다.
