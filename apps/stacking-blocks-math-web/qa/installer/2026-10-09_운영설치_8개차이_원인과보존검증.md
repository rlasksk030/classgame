## RPC 의미 비교

실제 `sb_save_building`의 전체 정의 MD5는 `a3d50f55b3a825e5c45824b028f67e15`이며
`20261002104459_live_v4_compatibility.sql`로 생성한 정의와 바이트 단위로 같다.
단순 PostgreSQL 표기 차이가 아니라 **과거 배포한 정상 함수 정의**다.

manual-required 기준과의 유일한 본문 차이는 새 작품이고 판 크기를 생략했을 때
`coalesce(prior.grid_width,10)` / depth의 기본값이 **5**인 것이다.
학생·학급 소속 검사, active 검사, 행 잠금, 버전 충돌 검사, 좌표/재료 저장,
진도 처리, SECURITY DEFINER, `search_path=public`, 소유자와 실행 권한은 같다.
기존 작품에 저장된 판 크기나 명시된 입력 크기는 이 fallback 변경의 대상이 아니다.
기존 10칸/3층 제한까지 새롭게 올바르다고 주장하지 않으며, 이번 설치 복구에서
함수의 학습 기능 계약을 바꾸거나 이전 함수로 덮어쓰지 않는다.

public 기본 ACL에는 CRUD opt-out 이후 남은 Dxtm이 있지만 이는 미래 객체의 기본값이며
현재 테이블의 SELECT 권한을 무효화하지 않는다. 기본 ACL은 변경하지 않는다.

기존 `C_MISSING_PERMISSION`은 가장 가까운 *과거* 기준과의 차이다.
여기서 Dxtm을 다시 GRANT하는 것은 복구가 아니라 불필요한 권한 확대이므로 하지 않는다.

  기존 27개 모델·migration·catalog SQL은 수정하지 않는다.

  그대로 편입하거나, 8개 필드를 무시하거나, 모든 구형 함수 해시를 허용하지 않는다.

  PIN hash, 기존 답안·채점·점수·XP·진도·작품은 바꾸지 않는다.
