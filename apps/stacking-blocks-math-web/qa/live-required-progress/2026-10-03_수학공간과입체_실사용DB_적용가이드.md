## Edge — 선택한 공식 경로: 기존 소유자의 CLI

다중 파일 import와 원본 재배포 복구가 필요하므로 **CLI로 student-api 하나만 배포**하는 경로를 선택했습니다. Dashboard의 기존 함수 ZIP 반입 UI는 직접 재확인하지 못했으며 지원한다고 가정하지 않습니다. Dashboard Code 편집기는 자동 버전 복구를 제공하지 않습니다. 공식 문서: [CLI 배포](https://supabase.com/docs/guides/functions/deploy), [Dashboard 편집/다운로드](https://supabase.com/docs/guides/functions/quickstart-dashboard), [기본 환경 변수](https://supabase.com/docs/guides/functions/secrets).

아래 명령은 현재 실행하지 않았습니다. **이미 이 프로젝트 권한이 있는 CLI 환경**에서만, 적용 승인을 받은 뒤 사용합니다. 로그인 권한이 없거나 CLI가 동작하지 않으면 중단합니다. 새 권한/토큰/키를 이 가이드로 발급하거나 복사하지 않습니다. 명령에 secret 값이 없습니다.

이 공개 문서는 실행용이 아닙니다. CLI·패키지·프로젝트 경로는 로컬 비공개 가이드에서 확인합니다. placeholder가 남은 명령은 실행하지 않습니다. 검증한 CLI는 2.75.0입니다.

```sh
MATH_SUPABASE_CLI='OWNER_VERIFIED_SUPABASE_CLI'
MATH_PACKAGE='PRIVATE_APPROVED_PACKAGE'
MATH_PROJECT_REF='PRIVATE_PROJECT_REF'
"$MATH_SUPABASE_CLI" --version
"$MATH_SUPABASE_CLI" functions deploy --help
"$MATH_SUPABASE_CLI" functions download --help
"$MATH_SUPABASE_CLI" --workdir "$MATH_PACKAGE/B_Edge/target" functions list --project-ref "$MATH_PROJECT_REF" -o json
```

배포 전 list 결과에서 두 함수의 version/status/updated_at(배포 시각 필드)를 기록합니다. 정확한 시간 필드가 없으면 Dashboard/공식 Management metadata로 확인합니다. 기존 Settings의 verify_jwt도 읽고 source archive와 hash를 확보합니다. student-auth version/source가 없으면 DB APPLY도 시작하지 않습니다.

Secrets는 Dashboard **Edge Functions → Secrets**에서 이름만 기록합니다. APP_SESSION_SECRET은 앱 설정 이름입니다. SUPABASE_URL/ANON_KEY/SERVICE_ROLE_KEY는 호스팅 기본 환경 변수로 일반 사용자 secrets 목록에 나타나지 않을 수 있습니다. 목록에 없다고 새 값을 만들거나 기본 키를 추출하지 않습니다.

DB POSTCHECK가 전부 PASS한 뒤에만 다음 **한 함수 배포** 명령을 실행합니다. 34파일 target-manifest hash와 소스를 먼저 대조합니다. `--no-verify-jwt`는 기존 OFF 설정을 그대로 유지하는 옵션이며 함수 내부 학생 HMAC/session·교사 Auth 검증은 유지합니다.

```sh
"$MATH_SUPABASE_CLI" --workdir "$MATH_PACKAGE/B_Edge/target" functions deploy student-api --project-ref "$MATH_PROJECT_REF" --use-api --no-verify-jwt
"$MATH_SUPABASE_CLI" --workdir "$MATH_PACKAGE/B_Edge/target" functions list --project-ref "$MATH_PROJECT_REF" -o json
```

함수 이름 없는 deploy, --prune, student-auth deploy, secrets set은 사용하지 않습니다. 배포 후 새 ACTIVE version/deployed_at/verify_jwt를 기록하고 source를 다시 받아 target과 import 경로 포함해 비교합니다. source root가 변경되는 경우 내용·의존성 대응표로 검증하며 로컬 bundle hash를 remote ezbr hash와 같다고 주장하지 않습니다.

실패 시 같은 실사용 직전 원본 32파일로 아래 복구 명령을 사용합니다. 복구 source/version이 적용 직전과 연결되어 있지 않으면 자동으로 복구하지 않습니다.

```sh
"$MATH_SUPABASE_CLI" --workdir "$MATH_PACKAGE/B_Edge/rollback-cli" functions deploy student-api --project-ref "$MATH_PROJECT_REF" --use-api --no-verify-jwt
"$MATH_SUPABASE_CLI" --workdir "$MATH_PACKAGE/B_Edge/rollback-cli" functions list --project-ref "$MATH_PROJECT_REF" -o json
```

복구도 새 version을 만드는 재배포입니다. 이전 숫자 version으로 되감는 기능이 아닙니다. auth·secrets는 그대로 둡니다. 복구 후 기존 frontend의 합성 인증·읽기·저장 smoke가 필요합니다.

## 중단 및 복구

- DB 전: identity/schema/Edge version/source/hash/행수/backfill 미확정 또는 불일치면 APPLY 금지.
- DB 후: SQL 실패/POSTCHECK false/row loss/예상 외 객체 변경이면 Edge 금지. transaction failure는 전체 rollback과 metadata 재확인. commit 뒤에는 학생 자료 삭제나 DROP으로 복구하지 않고 구 API 호환성을 유지한 forward-fix를 검토합니다. 백업한 기존 3개 RPC 정의는 비교 근거이며 자동 down migration이 아닙니다.
- Edge 후: 인증/소유권/저장/보존 smoke 실패면 PR Ready/merge/Render 금지. 실제 직전 API source만 복구하고 기존 auth·secrets 유지.
- installer: pending 4개 자동 실행을 허용하거나 history를 속여 통과시키지 않습니다. 이 단계 해소 전 전체 운영 승격 최종 완료로 보고하지 않습니다.

## 적용 전 Edge 원본을 보관하는 Dashboard 클릭 경로

1. Projects → 대상 프로젝트 → Edge Functions로 들어갑니다. URL의 project ID를 다시 확인합니다.
2. 기존 student-api를 클릭합니다. Settings에서 verify_jwt 설정을 읽고 수정하지 않습니다.
3. 오른쪽 위 Download → Download as ZIP으로 현재 원본을 저장합니다. 함수 이름과 수집 시각을 파일명에 기록합니다.
4. 목록으로 돌아가 student-auth에도 같은 다운로드를 수행합니다. Deploy updates/Save changes/Delete/Reveal은 누르지 않습니다.
5. 버전·배포 시각은 공식 CLI list 결과와 대응시킵니다. 원본 ZIP SHA와 개별 source SHA를 로컬 manifest로 생성해 비교받습니다. Name hash 일치만으로 원본 byte 일치를 인정하지 않습니다.
6. 기존 API는 32파일, target은 34파일입니다. 버전·entrypoint·import 경로와 원본 bytes가 실제 적용 직전 상태에 연결되어야 합니다. auth 소스 미확보는 적용 중단 조건입니다.

아래 읽기 전용 다운로드는 이미 승인된 소유자 CLI에서만 사용할 수 있습니다. 다운로드 후 원본 파일 SHA를 다시 검증받고, 현재 패키지의 rollback source와 다르면 재확정합니다.

```sh
mkdir -p "$MATH_PACKAGE/B_Edge/readback-current/supabase"
"$MATH_SUPABASE_CLI" --workdir "$MATH_PACKAGE/B_Edge/readback-current" functions download student-api --project-ref "$MATH_PROJECT_REF" --use-api
"$MATH_SUPABASE_CLI" --workdir "$MATH_PACKAGE/B_Edge/readback-current" functions download student-auth --project-ref "$MATH_PROJECT_REF" --use-api
```
