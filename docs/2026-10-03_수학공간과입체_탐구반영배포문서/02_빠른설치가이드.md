# 빠른 설치 가이드
수학 공간과 입체
## 계정과 프로젝트 준비
□ 본인 Supabase 계정과 프로젝트를 준비합니다.
□ 요금과 프로젝트 한도를 확인합니다. 기존 프로젝트를 임의 삭제하지 않습니다.
## 앱에서 연결과 설치
□ /setup → 설치 시작하기 → Supabase 준비 → 연결 화면으로.
□ Supabase 연결 → 본인 계정 로그인·권한 승인.
□ 내 Supabase 프로젝트 → 이 프로젝트 사용 → 자동 설치로 계속.
□ 대상 확인 → 설치하기 → 상태 확인.
□ 교사 확인으로 계속 → 교사 계정 만들기 또는 이미 계정이 있어요.
□ 계정 준비 후 교사 로그인.
□ 우리 반 만들기 → 학급 선택 → 학생 만들기로 계속.
□ 학생 명단 → 학생 계정 만들기 → 학생 로그인 확인 → 완료 화면으로.
## 수업 전 마지막 확인
□ 링크 복사로 받은 전체 학급 링크를 학생에게 전달합니다.
□ 시험용 학생으로 한 문제 풀이·저장·새로고침·재로그인을 확인합니다.
□ 오늘의 안내된 탐구에서 관찰·조작·발견 내용이 차시에 맞는지 확인합니다.
□ 작업이 끝나면 설치 권한 해제, 교사 로그아웃을 확인합니다.
중단된 설치는 상태 확인 후 이어서 복구합니다. 새 프로젝트·학생을 반복 생성하지 않습니다. 개발자용 수동 연결은 기본 설치 절차가 아닙니다.
