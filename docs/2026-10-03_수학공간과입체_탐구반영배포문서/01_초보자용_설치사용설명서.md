# 초보자용 설치 사용 설명서
수학 공간과 입체
이 안내는 2026년 10월 3일 소스 기준 개정판입니다. 실제 접속 화면의 버전이 다르면 제작자에게 반영 상태를 확인하세요. 수업 전에는 시험용 학생으로 로그인·첫 저장·재접속을 확인합니다.
## 1 프로그램 소개
쌓기나무를 관찰하고 표현을 바꾸는 수학 활동입니다. 교사의 설명 뒤 학생이 짧게 직접 조작하도록 운영합니다.
확인과 문제해결: 학생은 학급 링크로 시작하며, 교사는 /teacher에서 학급을 관리합니다.
## 2 설치 전에 준비할 것
인터넷이 되는 기기, 본인 Supabase 계정과 프로젝트, 교사용 이메일을 준비합니다. 수업 기록은 연결한 본인 프로젝트에 저장됩니다.
확인과 문제해결: 프로젝트 생성 화면에 비용·요금제 변경이 나오면 내용을 확인한 뒤 결정하세요. 무료 한도 때문에 기존 프로젝트를 임의 삭제하지 않습니다.
## 3 Supabase 이해하기
Supabase는 학생 계정·진도·작품을 저장하는 서비스입니다. 교사마다 본인 프로젝트를 사용하는 구조입니다.
확인과 문제해결: 앱 웹주소와 Supabase 주소는 서로 다릅니다. 학생에게는 학급 링크를 줍니다.

## 4 Supabase 계정 만들기
Supabase 홈페이지에서 본인의 계정을 만들거나 로그인합니다. 다른 교사의 계정을 공용으로 돌려 쓰지 않습니다.
확인과 문제해결: 이메일 확인이 나오면 본인 받은편지함에서 처리합니다. 계정 생성·약관 동의는 본인이 진행합니다.
## 5 새 프로젝트 만들기
Supabase에서 본인 조직과 새 프로젝트를 준비합니다. 기존 수업 데이터가 있는 프로젝트를 시험용으로 사용하지 않습니다.
확인과 문제해결: 프로젝트 준비가 끝나면 앱 /setup으로 돌아옵니다. 결제나 조직 선택이 불명확하면 제작자에게 문의합니다.
## 6 Project URL 찾기
일반 설치는 Supabase 연결로 권한을 승인하고 내 Supabase 프로젝트에서 고릅니다. 정상 연결에서는 Project URL을 직접 복사하지 않아도 됩니다.
확인과 문제해결: 공개 연결 정보를 자동으로 가져오지 못한 경우에만 제작자의 안내에 따라 개발자용 수동 연결을 사용합니다.
## 7 Publishable key 찾기
일반 설치는 프로젝트 선택 후 공개 키도 자동으로 연결합니다. 키를 직접 입력하는 칸은 개발자용 수동 연결 안에 있습니다.
확인과 문제해결: 수동 입력이 꼭 필요한 경우에만 본인 프로젝트의 공개 Publishable key를 사용합니다. 관리용 Secret key나 service_role은 넣지 않습니다.

## 8 설치 페이지 접속
브라우저에서 https://stacking-blocks-math.onrender.com/setup을 엽니다. 공간과 입체 수업앱 설치 화면인지 확인합니다.
확인과 문제해결: 다른 기기에서 기존 설치를 연결하는 경우에도 새 프로젝트나 학급을 만들지 말고 기존 프로젝트를 선택합니다.
## 9 설치 첫 단계
처음 시작하기에서 설치 시작하기를 누릅니다. 상단에는 시작·연결 준비·연결·자동 설치·교사 확인·학급 생성·학생 생성·설치 완료의 8단계가 있습니다.
확인과 문제해결: 이전에 중단했다면 이어서 설치하기 또는 설치 상태 확인 / 복구를 사용합니다. 설치를 처음부터 반복하지 않습니다.
## 10 Supabase 준비 단계
Supabase 준비에서 Supabase 열기로 본인 계정과 프로젝트를 확인한 뒤 연결 화면으로를 누릅니다.
확인과 문제해결: 외부 서비스 화면은 변경될 수 있습니다. 앱에서는 다음 Supabase 연결 단계의 권한 승인 흐름을 사용합니다.

## 11 연결 단계
Supabase 연결을 누르고 본인 계정으로 로그인해 권한을 승인합니다. 돌아온 화면에서 내 Supabase 프로젝트를 고르고 이 프로젝트 사용을 누릅니다.
확인과 문제해결: Supabase 연결 완료와 선택한 프로젝트를 확인하고 자동 설치로 계속을 누릅니다. 프로젝트가 없으면 먼저 본인 계정에 준비합니다.
## 12 자동 설치 단계
설치 대상과 상태를 확인하고 설치하기를 누릅니다. 앱이 데이터 구조와 학생 로그인·학습 기능을 준비합니다.
확인과 문제해결: 상태 확인으로 진행 상태를 봅니다. 중단됐다면 이어서 복구를 사용합니다. 정상 교사 흐름에서는 개발자용 임시 설치 권한 토큰을 입력하거나 터미널·SQL을 실행하지 않습니다.
## 13 교사 확인 단계
교사 확인으로 계속을 누릅니다. 교사 계정에서 교사 계정 만들기를 선택해 이메일과 비밀번호를 입력하고 계정 만들기를 누릅니다. 생성 후 같은 정보로 교사 로그인합니다.
확인과 문제해결: 기존 계정이면 이미 계정이 있어요를 선택합니다. Supabase 관리 계정과 수업앱 교사 계정을 혼동하지 않습니다. 이 화면에서 계정 생성이 막히면 제작자에게 문의합니다.

## 14 학급 만들기
우리 반 만들기에서 새 학급 이름을 입력하고 학급 만들기를 누릅니다. 선택한 학급과 자동 생성된 코드를 확인합니다.
확인과 문제해결: 기존 학급이 있으면 기존 학급 선택을 사용합니다. 중복 생성하지 말고 학생 만들기로 계속을 누릅니다.
## 15 학생 만들기
학생 만들기의 학생 명단에 한 줄에 한 명씩 또는 쉼표로 이름을 넣습니다. 준비 인원수를 확인하고 학생 계정 만들기를 누릅니다.
확인과 문제해결: 생성된 PIN은 공개하지 않고 학생별로 전달합니다. 다시 접속했다고 학생 계정을 재생성하지 않습니다. 학생 로그인 확인을 마친 뒤 완료 화면으로 갑니다.
## 16 설치 완료 확인
설치 준비가 끝났어요 화면에서 연결·교사 로그인·학급·학생·학생 로그인 확인 상태를 점검합니다. 링크 복사로 학생 접속 링크를 보관합니다.
확인과 문제해결: 화면 안내대로 첫 학습 저장·재접속 복원까지 확인해야 실제 수업 준비가 끝납니다. 현재 화면은 QR 자동 표시를 약속하지 않으며 링크를 QR 생성기에 넣으라고 안내합니다.

## 17 교사 로그인
교사 주소 /teacher에서 이메일·비밀번호를 입력하고 로그인을 누릅니다. 로그인 뒤 교사 관리가 보입니다.
확인과 문제해결: 학생 PIN으로 교사 로그인을 할 수 없습니다. 공용 기기에서 비밀번호 저장을 권장하지 않습니다.
## 18 교사 화면 기본 사용
반 선택에서 사용할 학급을 확인합니다. 학생 PIN 관리·차시 잠금·놀이와 건축물 기록을 살펴봅니다.
확인과 문제해결: 변경 전에 현재 학급을 다시 확인합니다. 공개 화면에는 학생 PIN 관리 목록을 띄우지 않습니다.
## 19 학급 관리
새 학급 만들기로 학급을 추가할 수 있습니다. 이미 있는 반은 반 선택에서 선택합니다. 학생 링크 복사는 선택한 반 기준입니다.
확인과 문제해결: 작년 학급을 새 학급처럼 재사용하거나 진도를 임의 초기화하지 않습니다. 삭제는 수업 중 문제해결 방법이 아닙니다.
## 20 학생 계정과 PIN 관리
학생 추가 또는 명단 미리보기 후 인원수 생성 버튼을 사용합니다. 이름 수정·PIN 재발급·비활성 등의 작업은 해당 학생을 확인하고 진행합니다.
확인과 문제해결: PIN 재발급 뒤에는 새 PIN을 본인에게만 전달합니다. 전체 PIN 복사와 학생 로그인표 인쇄 결과는 교사가 안전하게 관리합니다.

## 21 학생 접속 방법 전달
교사 화면의 학생 링크 복사로 얻은 전체 주소를 학생에게 전달합니다. 학급 코드만 임의로 붙여 만든 주소보다 앱이 만든 링크를 사용합니다.
확인과 문제해결: QR은 전체 학급 링크만 담습니다. PIN이나 교사 비밀번호를 넣지 않습니다. 다른 기기에서 QR을 열어 반이 맞는지 확인합니다.
## 22 학생 로그인
학급 링크를 열고 이름 또는 번호를 선택한 뒤 PIN 4자리를 입력하고 들어가기를 누릅니다. 정상이라면 공간과 입체 월드가 열립니다.
확인과 문제해결: 선생님이 주신 수업 링크로 들어와 주세요가 보이면 기본 홈페이지가 아니라 학급 링크를 다시 엽니다.
## 23 학생 화면 구조
학생 홈에서 차시와 진행 상태를 확인합니다. 개념 배우기 안의 안내된 탐구, 문제 풀기, 선택 연습은 목적이 다릅니다.
확인과 문제해결: 이미 학습한 차시는 서버에 저장된 단계로 이어질 수 있습니다. 탐구를 보려고 진도를 초기화하지 말고 수업 전 시험용 학생으로 확인합니다.

## 24 1~12차시 이용하기
안내된 탐구는 차시마다 다릅니다. 1차시는 세기, 2~3차시는 방향과 투영, 4차시는 높이·층, 5~6차시는 정보와 여러 해, 7~8차시는 지도 편집, 9~11차시는 제작·소개, 12차시는 표현 연결입니다.
확인과 문제해결: 화면의 관찰 → 조작 → 발견 안내를 차례로 읽고 실제로 한 번 바꾸어 보게 합니다. 구체적인 버튼과 수업 질문은 04 수업운영가이드에 있습니다.
## 25 문제 풀이 방법
질문과 자료를 먼저 보고 선택지·숫자·격자·블록 중 현재 문제의 입력 방법을 사용합니다. 입력 후 정답 확인을 누르고 피드백을 읽습니다.
확인과 문제해결: 알 수 있어요 / 알 수 없어요 유형은 선택으로 답합니다. 앞모습만으로 묻는 문제에 숨겨진 원본 개수를 추측해 넣지 않습니다.
## 26 3D 쌓기나무 조작
빈 공간을 끌면 회전하고 휠·두 손가락으로 확대합니다. 자유 보기·위에서 보기·앞에서 보기·옆에서 보기·원래 위치를 사용합니다. 편집이 가능한 화면에서는 보관함 드래그와 버튼으로 놓기를 사용합니다.
확인과 문제해결: 위치 선택 문제는 기준 표시가 붙은 빨간 블록을 먼저 찾고 답이 되는 블록을 탭합니다. 선택한 블록 문구를 확인한 뒤 제출합니다. 회전과 선택을 구분하며, 관찰 전용 문제에서는 임의로 쌓을 수 없습니다.

## 27 추가 연습
문제 풀기를 끝낸 후 다음 단계로 추가 연습에 들어갑니다. 문제 수는 교사 배정과 활성 묶음에 따라 달라집니다.
확인과 문제해결: 새 문제 더 풀기는 새 묶음 시작입니다. 완료한 기존 기록을 지우는 기능으로 설명하지 않습니다. 최신 유형 수정이 오래된 묶음에 소급 적용되지 않을 수 있습니다.
## 28 진도 저장과 복원
문제 풀이 결과와 작품 저장은 저장 안내를 확인한 뒤 이동합니다. 같은 학급·같은 학생으로 다시 로그인해 이어서 진행합니다.
확인과 문제해결: 안내된 탐구의 임시 쌓기·지도 조작은 문제 답안이나 점수로 기록되지 않습니다. 9~11차시 작품과 12차시 자기평가는 각각의 저장 기능을 사용합니다. 탐구 화면의 모형이 초기화된 것과 문제 진도 소실을 구분합니다.
## 29 9차시 문제 만들기와 친구 문제
10개 모형을 만든 뒤 10개 완성 → 문제 카드 고르기, 이 카드로 정하기 →, 힌트 카드 확인 →, 이 문제 저장 순서로 진행합니다. 친구 문제 또는 기본 연습을 선택해 풉니다.
확인과 문제해결: 학생 제작 문제가 부족하면 시스템 기본 연습이 보충됩니다. 힌트 없이 해결하면 놀이 점수 2점, 힌트 사용 후에는 1점입니다. 자기 문제와 반복 제출로 점수를 늘리지 않습니다.

## 30 10차시 건축물
건축물 이름과 설계 이유를 적고 작품을 만듭니다. 10차시 설계 저장을 누르고 저장 성공 안내를 확인합니다.
확인과 문제해결: 작업판 크기와 제공 도구는 현재 작품 화면에서 확인합니다. 다른 학생의 작품과 혼동하지 않도록 제목과 학생 계정을 함께 확인합니다.
## 31 11차시 이어서 작업
같은 학생으로 11차시에 들어가 10차시 작품의 제목·모양을 확인하고 소개를 이어 씁니다. 새 빈 작품이 나타나면 먼저 계정과 저장 성공 여부를 확인합니다.
확인과 문제해결: 새 작품으로 덮어쓰거나 기존 작품을 지우지 않습니다. 소개서 미리보기와 실제 파일 저장은 화면에 제공된 버튼 범위에서 사용합니다.
## 32 12차시 종합과 자기평가
단원 문제를 풀고 단원 돌아보기에서 나의 자신감과 배운 점을 작성한 뒤 자기평가 저장을 누릅니다. 자기평가는 정오답 점수가 아닙니다.
확인과 문제해결: 저장 후 새로고침하여 값이 돌아오는지 확인합니다. 공통·맞춤 문제 수는 현재 학생에게 배정된 목록과 화면의 진행률을 기준으로 봅니다.

## 33 완료 후 다음으로 이동
완료 결과를 읽고 다음 문제가 있으면 다음 문제, 단계 끝이면 다음 단계, 마지막이면 학습 완료를 누릅니다. 자동 이동을 기다리지 않아도 됩니다.
확인과 문제해결: 상단 문제 풀기의 완료 표시와 현재 단계를 함께 봅니다. 저장이 실패하면 현재 화면에 남습니다. 버튼이 계속 비활성이면 오류 문구와 차시·문항 번호를 제작자에게 전달합니다.
## 34 업데이트 확인과 적용
설치 화면의 설정 확인 / 복구에서 연결을 확인하고 설치 권한 연결 단계의 상태 확인을 사용합니다. 승인된 지원 환경에서만 업데이트를 누릅니다.
확인과 문제해결: 학생이 사용하지 않는 시간에 진행하고, 기존 기록의 보존·버전 호환성을 제작자에게 확인합니다. 브라우저 새로고침만으로 서버 함수가 업데이트되지는 않습니다.
## 35 설치 상태 확인과 복구
중단했다면 설치 상태 확인 / 복구로 돌아갑니다. 대상 프로젝트를 확인하고 필요할 때 권한을 다시 연결한 후 이어서 복구를 사용합니다.
확인과 문제해결: 완료된 단계가 보존되는지 확인합니다. 학생·프로젝트를 삭제하거나 DB 초기화로 해결하지 않습니다. 같은 실패가 반복되면 중지하고 제작자에게 문의합니다.

## 36 권한 해제
설치 권한 해제를 눌러 설치 서버의 권한 사용을 끝냅니다. Supabase 계정의 앱 연결 권한 관리도 필요에 따라 확인합니다.
확인과 문제해결: 권한 해제는 학생 기록 삭제가 아닙니다. 본인 프로젝트와 기존 학급은 그대로 보존합니다.
## 37 수업 종료 후 관리
학생은 월드로 돌아가 나가기를 누르고, 교사는 교사 로그아웃을 누릅니다. 공동 기기의 다음 학생이 이전 학생 화면을 보지 않는지 확인합니다.
확인과 문제해결: PIN 인쇄물과 교사 계정은 안전하게 보관합니다. 보존·삭제 시기는 학교의 학생 데이터 관리 방침에 따릅니다. 오류 문의에는 비밀번호·PIN·토큰을 첨부하지 않습니다.
