# 수업 운영 가이드
안내된 탐구는 개념을 조작해 발견하는 활동입니다. 화면의 관찰·조작·발견을 읽고 한 번 바꾼 결과를 학생에게 말하게 하세요. 문제 풀이의 답안 제출과는 구분합니다.
## 수업 전 5분 점검
□ 학급 링크·학생 로그인  □ 오늘 차시 열림 상태  □ 자료와 조작 도구
□ 문제 저장·새로고침  □ 공용 기기의 이전 학생 로그아웃
## 탐구와 진도의 구분
탐구 중 임시로 바꾼 모형은 문제 답안·점수로 기록되지 않습니다. 이미 완료한 단계는 서버 기록에 따라 이어서 할 화면으로 이동할 수 있습니다. 화면을 다시 보려고 학생 진도를 초기화하지 마세요. 9~11차시 활동과 12차시 자기평가는 해당 저장 기능을 사용합니다.

## 1차시 쌓고 세어 보세요
관찰: 자리와 층에 따라 블록이 놓여 있어요.
조작: 블록을 추가하거나 선택해 삭제하고, 먼저 센 개수를 입력해 비교하세요.
화면에서 찾기: 개수 비교
발견을 묻기: 보이지 않는 블록도 전체 개수에 포함돼요.
## 2차시 같은 입체, 다른 관찰 위치
관찰: 모형은 그대로 두고 앞·뒤·왼쪽·오른쪽·위에서 보세요.
조작: 보기 버튼과 회전으로 관찰 위치를 바꾸세요.
화면에서 찾기: 앞에서 보기 · 뒤에서 보기 · 왼쪽에서 보기 · 오른쪽에서 보기 · 위에서 보기
발견을 묻기: 입체가 같아도 보는 방향에 따라 모습은 달라져요.

---PAGE---
## 3차시 입체와 세 방향 모양을 연결해요
관찰: 같은 입체의 위·앞·오른쪽 옆 모양을 비교하세요.
조작: 확인할 방향을 고르고, 모형을 돌려 해당 격자와 비교하세요.
화면에서 찾기: 위 모양 확인 · 앞 모양 확인 · 오른쪽 옆 모양 확인
발견을 묻기: 세 방향 격자는 같은 입체의 서로 다른 정보를 담아요.
## 4차시 자리별 높이와 층별 개수
관찰: 높이 지도와 층별 지도가 같은 블록을 나타내요.
조작: 한 블록을 추가하거나 선택해 삭제하고 두 지도의 변화를 보세요.
화면에서 찾기: 쌓기 도구와 높이 지도·층별 지도
발견을 묻기: 자리별 높이의 합 = 층별 개수의 합 = 전체 블록 수예요.

---PAGE---
## 5차시 앞모습만으로 개수를 알 수 있을까요?
관찰: 지금 주어진 정보는 앞에서 본 격자 하나뿐이에요. 사선 그림은 주어지지 않았어요.
조작: 먼저 판단한 뒤 가능한 두 입체를 번갈아 보고, 높이 정보를 추가해 비교하세요.
화면에서 찾기: 알 수 있다 / 알 수 없다 → 다른 가능한 입체 보기 → 높이 정보 추가
발견을 묻기: 앞모습이 같아도 개수는 다를 수 있어요. 추가 정보가 필요해요.
지도할 점: 처음 공개된 자료는 앞 격자 하나입니다. 사선 그림에서 보이는 정보를 같은 조건으로 취급하지 않습니다.
## 6차시 세 방향 조건에 맞는 여러 입체
관찰: 2×2판, 각 자리 2층 이하, 아래가 받쳐진 입체예요. 세 격자를 모두 만족해야 해요.
조작: 조건에 맞게 쌓고 비교하세요. 같은 조건의 예시도 바꾸어 보세요.
화면에서 찾기: 세 방향 조건 비교 · 조건에 맞는 다른 예 보기
발견을 묻기: 세 방향이 같아도 입체가 하나로 정해지지는 않아요. 이 조건의 최소·최대도 비교해요.
지도할 점: 이 탐구의 2×2판·각 자리 2층 이하라는 범위를 먼저 확인합니다. 모든 입체에 같은 결론을 적용하지 않습니다.

---PAGE---
## 7차시 숫자를 바꾸면 입체도 바뀌어요
관찰: 각 숫자는 그 자리에 쌓인 블록 수예요.
조작: 높이 지도의 ＋와 －를 눌러 입체를 바꾸세요.
화면에서 찾기: 높이 지도 각 칸의 ＋와 －
발견을 묻기: 높이 지도는 각 기둥의 높이를 정해요. 같은 숫자로 같은 입체를 복원해요.
## 8차시 층을 합쳐 입체를 만들어요
관찰: 각 층의 같은 자리가 위아래로 이어져요.
조작: 편집할 층을 고르고 칸을 켜거나 끄세요. 3D의 층 보기로 확인하세요.
화면에서 찾기: 편집할 층 · 층별 격자 셀 · 현재 층만 보기
발견을 묻기: 윗층 블록 아래에는 받쳐 주는 블록이 있어야 해요.

---PAGE---
## 9차시 문제를 만들고 친구에게 도전해요
관찰: 내 모형과 친구에게 공개할 카드·힌트를 구별해요.
조작: 아래 제작 화면에서 10개를 쌓고 카드를 고르거나 친구·기본 연습을 선택하세요.
화면에서 찾기: 10개 완성 → 문제 카드 고르기
발견을 묻기: 같은 공개 조건을 만족하는 답을 인정하며, 힌트 사용에 따라 놀이 점수가 달라져요.
지도할 점: 친구 문제와 시스템 기본 연습을 구별합니다. 제작한 원본과 친구에게 공개되는 카드·힌트를 따로 확인합니다.
## 10차시 내 건축물을 설계해요
관찰: 작업판과 작품의 여러 방향을 살펴보세요.
조작: 기존 제작 화면에서 쌓고 제목·설계 이유를 기록해 저장하세요.
화면에서 찾기: 10차시 설계 저장
발견을 묻기: 자유롭게 만든 작품도 여러 표현으로 설명할 수 있어요.
지도할 점: 자유 건축은 이 차시의 목적입니다. 제목·설계 이유와 저장 결과를 확인합니다.

---PAGE---
## 11차시 내 작품을 표현하고 소개해요
관찰: 10차시에서 저장한 같은 작품을 불러와요.
조작: 위·앞·옆과 층별 모습을 확인하고 용도와 소개를 작성하세요.
화면에서 찾기: 설계 저장
발견을 묻기: 입체의 표현과 공간 설명이 작품을 소개하는 근거가 돼요.
지도할 점: 10차시의 같은 학생·같은 작품인지 먼저 확인합니다. 작품을 새로 만들지 않습니다.
## 12차시 여러 표현으로 같은 입체 설명하기
관찰: 하나의 입체를 높이·투영·층별 지도로 비교해요.
조작: 높이를 바꾸고 표현을 전환한 뒤, 아래 자기평가에 발견한 점을 기록하세요.
화면에서 찾기: 높이로 보기 · 세 방향으로 보기 · 층별로 보기 · 자기평가 저장
발견을 묻기: 표현이 달라도 가리키는 입체와 전체 개수는 같아요.

## 공통 조작과 문제 풀이
빈 공간을 끌어 회전하고, 선택해야 할 블록은 짧게 탭합니다. 위치 문제에서는 빨간 기준 표시와 선택한 블록을 구분합니다. 옆은 오른쪽 옆을 뜻하며 앞 기준을 먼저 확인합니다.
숫자 지도는 －로 줄이고 ＋로 늘립니다. 경계에 도달한 버튼은 비활성화될 수 있습니다. 숫자를 고친 뒤 현재 문제의 제출 버튼을 누릅니다.
## 완료와 선택 연습
결과를 읽은 뒤 다음 문제·다음 단계·학습 완료 중 현재 화면의 버튼을 사용합니다. 선택 연습을 많이 푼 수와 필수 차시 완료 수는 다릅니다. 현재 활성 문제 묶음의 수와 진행률을 확인합니다.
## 교사 문제 미리보기
교사의 문제 미리보기에서 차시와 한글 문제 틀 이름을 골라 자료·입력 방식을 확인합니다. 개별 문제 미리보기는 안내된 탐구 활동 전체와는 다른 화면입니다.
## 학생이 막혔을 때
질문 → 공개 자료 → 입력 방식 → 선택 상태 순서로 확인합니다. 저장 오류가 있으면 무작정 연타하거나 학생·학급·작품을 삭제하지 않습니다. 차시·단계·오류 문구를 제작자에게 전달합니다.
