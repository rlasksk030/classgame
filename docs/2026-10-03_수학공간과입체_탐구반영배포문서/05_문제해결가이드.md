# 문제해결 가이드
학생·학급·작품을 삭제하거나 초기화하는 방법으로 오류를 해결하지 마세요. 같은 실패가 반복되면 화면의 오류 문구와 차시·단계를 제작자에게 전달합니다. PIN·비밀번호·키는 보내지 않습니다.
## 설치 또는 연결이 멈췄어요
제공받은 전체 HTTPS 주소인지 확인합니다. 설치 서버의 첫 응답이 늦을 수 있으므로 잠시 기다린 뒤 한 번 다시 확인합니다. Supabase 다시 연결이 보이면 같은 계정과 기존 프로젝트로 승인합니다. 새 프로젝트를 만들 필요는 없습니다.
## 설치 중간에 나갔어요
이어서 설치하기 또는 설치 상태 확인 / 복구에서 같은 대상을 확인합니다. 상태 확인 후 필요한 경우 이어서 복구를 사용합니다. 이미 설치한 데이터를 지우지 않습니다.
## 다른 기기에서 교사 로그인이 안 돼요
기존 설치를 다시 연결한 뒤 같은 교사 계정으로 로그인합니다. Supabase 관리 계정과 앱 교사 계정은 구별합니다. 비밀번호를 잊었으면 로그인 화면의 복구 안내를 사용합니다.
## 학생 또는 학급이 안 보여요
선택한 프로젝트·교사 계정·학급을 확인합니다. 없다고 바로 중복 생성하지 않습니다. 학생은 교사가 복사한 전체 학급 링크로 들어갑니다.

## PIN을 잊었어요
교사가 해당 학생의 PIN 재발급을 사용하고 새 값을 본인에게만 전달합니다. 공개 수업 화면이나 전체 안내문에 PIN을 올리지 않습니다.
## 탐구가 모두 같은 자유 쌓기로 보여요
이 개정판에서는 1~12차시의 안내된 탐구가 서로 다른 활동입니다. 새로고침 후에도 같으면 접속 주소·차시·화면을 제작자에게 알려 배포 버전을 확인받습니다. 학생 진도를 초기화하지 마세요.
## 탐구에서 바꾼 모형이 다시 처음으로 돌아와요
안내된 탐구의 임시 모형 조작은 문제 답안·점수 저장과 별개입니다. 9~11차시 작품은 저장 버튼의 결과를, 12차시 자기평가는 자기평가 저장 결과를 확인합니다.
## 이미 끝낸 차시에서 탐구가 안 열려요
서버가 기억한 학습 단계로 이어질 수 있습니다. 수업 전 전체 활동을 살펴볼 때는 시험용 학생을 사용합니다. 기존 학생의 기록을 지워서 다시 보게 하지 않습니다.
## 진도나 작품이 사라진 것 같아요
같은 학급과 학생인지 확인하고 저장 안내를 봅니다. 새로고침과 나가기 후 재로그인을 시도합니다. 11차시에서는 10차시에 저장한 같은 작품인지 확인합니다. 계속 다르면 제작자에게 문의합니다.

## 3D 화면이나 블록 선택이 어려워요
저장 가능한 작품은 먼저 저장합니다. 원래 위치로 돌아가고, 회전은 빈 공간에서 시작합니다. 위치 문제의 기준 표시는 답으로 고른 블록 표시와 다릅니다. 기기·브라우저·차시를 함께 알려 주세요.
## 숫자나 층을 잘못 바꿨어요
숫자는 － 또는 ＋로 반대 방향으로 고칩니다. 층별 칸은 다시 눌러 지울 수 있지만 위 블록이 있으면 위부터 지워야 합니다. 공중에 뜨는 블록을 만들 수 없는 것은 정상입니다.
## 다음 문제로 안 넘어가요
결과를 읽고 다음 문제·다음 단계·학습 완료를 누릅니다. 저장 오류가 보이면 연결 상태를 확인합니다. 이미 완료한 문제인데도 계속 막히면 차시·문항·상단 단계·오류 문구를 전달하고 반복 제출은 멈춥니다.
## 업데이트와 권한 해제
학생이 사용하지 않는 시간에 설치 상태를 확인하고 지원되는 업데이트·복구 경로를 사용합니다. 설치 권한 해제는 학생 기록 삭제가 아닙니다. 터미널·SQL·함수 수동 배포를 일반 교사의 기본 해결책으로 삼지 않습니다.
