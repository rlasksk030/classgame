# 먼저 읽어 주세요
초등학교 6학년 수학 「공간과 입체」 1~12차시를 위한 교사용 안내입니다. 교사는 학급과 학생을 준비하고, 학생은 학급 링크에서 이름 또는 번호와 PIN으로 들어갑니다.
## 이번 개정판에서 달라진 안내
안내된 탐구는 전 차시 공통 자유 쌓기가 아닙니다. 관찰할 자료와 조작 방법이 차시마다 다릅니다. 04 수업운영가이드에서 각 차시의 관찰·조작·발견을 먼저 확인하세요.
## 설치와 학생 접속
본인 Supabase 계정과 프로젝트 준비 → /setup의 Supabase 연결 → 프로젝트 선택 → 자동 설치 → 교사 계정 → 학급 → 학생 → 학생 로그인·저장·재접속 확인 순서입니다. 일반 흐름에서는 관리 토큰을 직접 입력하지 않습니다.
## 자료 선택
처음 설치할 때는 01 상세 설명서, 다시 확인할 때는 02 빠른 설치, 설치 중 점검은 03 체크리스트를 봅니다. 수업 직전에는 04 수업운영, 문제가 생겼을 때는 05 문제해결을 사용하세요.
## 안전하게 사용하기
본인 프로젝트와 학급이 맞는지 확인합니다. PIN은 학생별로 전달하고 비밀번호·키·관리 토큰은 안내문에 넣지 않습니다. 공용 기기에서는 학생마다 나가기를 사용합니다.
이 안내는 2026년 10월 3일 소스 기준 개정판입니다. 실제 접속 화면의 버전이 다르면 제작자에게 반영 상태를 확인하세요. 수업 전에는 시험용 학생으로 로그인·첫 저장·재접속을 확인합니다.
