- 최종 스크린샷은 빈 학생 명단 화면이며 이름·이메일·PIN·토큰·프로젝트 URL/키가 없다. 설치 완료 증거처럼 사용하지 않았다.
- PDF 추출 텍스트, DOCX 내부 XML/관계, 텍스트 파일, 파일명/폴더 및 이미지 시각 검사를 수행했다. 실제 인증정보 패턴 0건. 안전한 설명용 용어와 실제 값은 구분했다.
- `.env*`, `.dev.vars`, node_modules, .git, QA runtime, 개인 로컬 경로, 학생 데이터는 ZIP에 미포함.
- ZIP 15파일 CRC 검사 PASS. 새 임시 폴더에 압축 해제 후 원본과 바이트 비교 PASS. 재압축 후 모든 항목 SHA-256 일치 PASS.
- 상세 해시·페이지 수는 `2026-09-20_수학공간과입체_패키지검증.json` 참조.

## 배포 상태

이 패키지는 **일반 교사 배포 승인 전 검토판**으로 표기했다. 현재 TEST 전용 PAT 설치와 허용목록을 일반 교사 자동 설치 완료로 바꾸어 설명하지 않았다. 학생 수업 기능의 기존 검증 결과와 일반 교사 설치의 미완료 조건은 최종 체크포인트에서 구분했다.

이번에 실제로 확인한 브라우저 범위는 학생 기본 진입, 설치 일부 단계, 교사 메뉴다. 모든 활동의 최신 화면을 새로 완주하거나 모든 설치 단계를 재실행한 것은 아니다. 전체 앱 QA를 문서 검수로 대체하지 않았다.

교사 화면 확인 중 도구 출력에 TEST PIN이 나타났으므로 해당 TEST PIN 재발급이 필요하다. 값은 문서·Git·ZIP에 기록하지 않았다. 원격 변경 금지에 따라 이 작업에서는 재발급하지 않았다.

## 제작자용 재생성

문서 본문은 동일 폴더의 Markdown과 `2026-09-20_수학공간과입체_문서제작.py`에 있다. 편집 가능한 DOCX도 문서원본에 보존한다. 교사 배포 ZIP에는 제작 스크립트나 개발 의존성을 넣지 않는다.

이번 변환은 번들 문서 런타임의 render_docx.py를 사용했다. Mac의 Arial Unicode MS를 변환용 임시 글꼴 폴더에 복사하고, 그 폴더만 가리키는 임시 fontconfig를 FONTCONFIG_FILE로 지정해 한글 누락을 해결했다. 시스템 글꼴 설정·앱 코드·저장소 설정은 변경하지 않았다. 글꼴 원본 파일은 배포하지 않는다.
