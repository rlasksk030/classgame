# 수업 운영 가이드
학생이 자료를 읽고 직접 조작한 다음 이유를 설명하도록 운영합니다. TEST 사이트에는 실제 학생 정보를 넣지 말고 정식 수업 주소부터 확인하세요.
## 수업 전 5분 점검
□ 학급 링크와 학생 계정 확인  □ 오늘 차시 잠금 상태 확인
□ 첫 문제의 자료·입력판 확인  □ 저장·새로고침 확인
□ 공용 기기의 이전 학생 로그아웃 확인
## 1차시 쌓기나무와 친해지기
학생 활동: 기준 블록과 위치를 구별하고 직접 쌓기.
교사 확인: 빨간 기준 표시와 학생이 선택한 블록을 구분합니다.
## 2차시 어느 방향에서 본 모양일까요
학생 활동: 앞·뒤·왼쪽·오른쪽에서 비교하기.
교사 확인: 학생이 바라보는 방향을 먼저 말하게 합니다.
## 3차시 세 방향 모습
학생 활동: 위·앞·오른쪽 옆의 격자 표현.
교사 확인: 그림과 입력판의 앞 기준을 함께 확인합니다.

## 4차시 쌓기나무의 개수
학생 활동: 자리별 높이와 층별 개수 비교.
교사 확인: 두 방법으로 센 합을 설명하게 합니다.
## 5차시 보이지 않는 쌓기나무
학생 활동: 정보 충분성과 가정에 따른 개수 판단.
교사 확인: 질문의 가정과 공개된 자료를 먼저 읽습니다.
## 6차시 세 방향에서 쌓기
학생 활동: 조건에 맞는 여러 입체 탐색.
교사 확인: 원본과 다르더라도 공개 조건을 만족할 수 있습니다.
## 7차시 높이 지도
학생 활동: 자리별 수로 모양 표현하기.
교사 확인: ＋와 －로 잘못 입력한 높이를 바로잡습니다.

학생 활동: 층별 표현을 합쳐 입체 이해하기.
교사 확인: 아래층의 지지와 층별 위치를 연결합니다.
## 9차시 쌓기나무 놀이터

교사 확인: 친구 문제와 시스템 기본 연습을 구별합니다.
## 10차시 건축물 만들기

교사 확인: 제목·설계 이유와 저장 결과를 확인합니다.

## 공통 조작 지도
빈 공간은 회전, 답 블록은 짧게 탭합니다. 앞 표시를 먼저 찾고 옆은 오른쪽 옆으로 읽습니다. 원래 위치로 시점을 되돌릴 수 있습니다. 격자 셀은 누르면 채워지고 다시 누르면 지워집니다.
높이 숫자는 ＋로 늘리고 －로 줄입니다. 0 아래나 9 위로 순환하지 않습니다. 잘못 누른 값은 반대 버튼으로 수정한 뒤 제출합니다.
## 완료와 추가 연습
학생이 피드백을 읽은 다음 다음 문제 또는 다음 단계를 누르게 합니다. 교사 화면의 추가 문제 수 선택은 5·10·15·20입니다. 현재 활성 묶음의 문제 수와 진행률을 기준으로 안내합니다.
## 학생이 막혔을 때
질문 → 공개 자료 → 입력 방식 → 선택 상태 순으로 확인합니다. 위치 문제는 빨간 기준 표시를 찾았는지 묻습니다. 개수·충분성 문제는 가정부터 읽습니다. 오류 상태에서 정답 확인을 반복하게 하지 않습니다.
## 저장과 계정
현재 기기에 임시 저장과 서버 저장 완료를 구분합니다. 작품을 이어 쓰려면 같은 학생 계정으로 들어갑니다. 학교 공용 기기에서는 매 학생이 나가기를 사용하게 합니다. 정오답·XP만으로 학생의 전체 성취를 단정하지 않습니다.
## 교사 문제 미리보기
교사 화면의 문제 미리보기에서 차시·문제 틀·seed를 골라 학생에게 보일 3D 모형과 문제 자료를 수업 전에 확인합니다. 문제 틀 이름은 한글 설명으로 표시됩니다.
확인: 화면 확인용이며 정답을 미리 알려주지 않습니다. 수업 전 확인 용도로만 사용합니다.
