# 빠른 설치 가이드
현재 제공 주소는 TEST 검증용입니다. 다른 교사의 실제 학생 명단을 입력하기 전, 제작자에게 정식 수업 주소와 본인 프로젝트 설치 지원 여부를 확인하세요. 현재 설치 화면은 TEST용 관리 토큰 직접 입력을 요구하므로 일반 교사 배포 준비가 모두 끝난 상태는 아닙니다.
## 먼저 제작자에게 확인
□ 정식 수업 주소와 본인 프로젝트 설치 지원 여부를 확인합니다.
□ 현재 TEST 서버는 일반 프로젝트를 자동으로 허용하지 않음을 확인합니다.
## Supabase 준비
□ 본인 계정으로 로그인하고 본인 조직에 프로젝트를 준비합니다.
□ Project URL과 Publishable key를 확인합니다.
□ 별도의 앱 교사 Auth 계정을 준비합니다.
## 앱의 8단계
□ 처음 시작하기 → 설치 시작하기.
□ Supabase 준비 → 연결 화면으로.
□ Project URL·Publishable key → 연결 확인.
□ 승인된 TEST 권한 연결 → 설치하기 → 설치 상태 확인.
□ 교사 확인으로 계속 → 교사 로그인.
□ 새 학급 이름 → 학급 만들기 → 학생 만들기로 계속.
□ 학생 명단 → 학생 계정 만들기 → 학생 로그인 확인.
□ 완료 화면으로 → 링크 복사 → 교사 화면 열기.
## 학생 기기에서 마무리
□ 복사한 학급 링크로 이름/번호와 PIN을 사용해 로그인합니다.
□ 한 문제를 풀고 저장한 뒤 새로고침·재로그인으로 복원을 확인합니다.
□ 설치 권한 해제 후 PIN 목록을 안전하게 보관합니다.
막히면 05 문제해결가이드를 봅니다. 일반 교사의 기본 해결책으로 터미널·SQL·함수 수동 배포를 요구하지 않습니다. 현재 설치 지원 범위 밖인 경우 제작자에게 문의하세요.
