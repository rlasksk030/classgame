# 문제해결 가이드
오류가 나도 학생·학급·작품을 삭제하거나 새 프로젝트로 바꾸지 마세요. 먼저 아래 순서대로 확인하고, 해결되지 않으면 제작자에게 차시·단계·오류 문구만 전달합니다.
## 설치 페이지가 열리지 않아요
제작자가 제공한 전체 HTTPS 주소인지 확인합니다. TEST Render 서비스가 쉬고 있었다면 첫 응답이 늦을 수 있습니다. 잠시 뒤 한 번 다시 열고 계속 실패하면 제작자에게 문의합니다. 다른 사이트의 비슷한 설치 화면에 키를 입력하지 않습니다.
## 연결 확인이 실패해요
Project URL과 Publishable key가 같은 본인 프로젝트에서 나온 것인지 확인합니다. 주소 앞뒤 공백과 Dashboard URL을 잘못 넣었는지 살펴봅니다. 키를 메신저로 보내서 확인받지 않습니다.
## 설치 권한을 연결할 수 없어요
현재 설치 서버는 TEST 전용이며 허용 프로젝트와 접속 주소를 검사합니다. 본인 프로젝트가 지원 대상인지 제작자에게 문의합니다. 권한 토큰은 만료되거나 서버가 재시작되면 다시 연결해야 합니다. 일반 교사 권한 연결 방식은 별도 준비가 필요합니다.
## 설치가 중간에 멈춰요
설치 상태 확인 / 복구 → 대상 확인 → 상태 확인 순서로 봅니다. 승인된 환경에서 이어서 복구를 사용합니다. 같은 단계가 반복 실패하면 중지합니다. 데이터 초기화나 SQL 복사 실행은 기본 해결책이 아닙니다.

## 교사 로그인이 안 돼요
Supabase 관리 계정이 아니라 해당 프로젝트 Authentication에 준비한 앱 교사 계정인지 확인합니다. 이메일 확인·비밀번호 복구가 필요하면 계정 소유자가 처리합니다. 임의 계정 생성·학생 삭제로 해결하지 않습니다.
## 학급 또는 학생이 안 보여요
교사 관리의 반 선택을 확인한 뒤 새로고침합니다. 다른 프로젝트를 연결했거나 다른 교사로 로그인했는지 확인합니다. 학급이 보이지 않는다고 중복 생성하지 않습니다.
## 학생 로그인이 안 돼요
기본 홈페이지가 아니라 교사가 복사한 전체 학생 링크를 엽니다. 학급·이름/번호·PIN 네 자리를 확인합니다. PIN을 잊었다면 교사가 PIN 재발급을 하고 새 값을 본인에게만 줍니다.
## 진도가 사라진 것 같아요
같은 학급과 학생인지 확인합니다. 저장 성공 안내를 확인하고 새로고침합니다. 나가기 뒤 다시 로그인합니다. 현재 기기에 임시 저장만 보였다면 연결을 복구하고 저장을 다시 확인하세요. 계정을 새로 만들지 않습니다.

## 3D 화면이 검거나 멈춰요
작업을 저장할 수 있으면 먼저 저장합니다. 원래 위치를 누르고 다른 탭을 줄입니다. 계속 멈추면 기기·브라우저·차시를 제작자에게 전달합니다. 이 자료는 모든 iPad/Safari 조합의 검증을 뜻하지 않습니다.
## 기준 블록이나 선택을 모르겠어요
빨간 기준 표시를 먼저 찾습니다. 정답 블록은 짧게 탭하고 선택한 블록 문구가 바뀌는지 확인합니다. 회전은 빈 공간에서 시작합니다. 설명이 옛 문장인 저장 묶음이면 교사가 제작자에게 문항 버전을 확인받습니다.
## 숫자를 너무 많이 올렸어요
숫자 왼쪽 －를 눌러 줄입니다. 오른쪽 ＋는 늘립니다. 0과 9에서 해당 방향 버튼이 비활성인 것은 정상입니다. 숫자 전체를 다시 순환시킬 필요가 없습니다.
## 다음 문제로 안 넘어가요
완료 결과를 읽고 다음 문제 / 다음 단계 / 학습 완료를 누릅니다. 저장 오류가 보이면 연결을 확인하고 다시 누릅니다. 이미 완료했는데도 계속 막히면 차시와 문항 번호·상단 단계·오류 문구를 제작자에게 전달합니다. 반복 제출로 해결하지 않습니다.
## 업데이트와 권한 해제
설정 확인 / 복구에서 현재 대상을 확인합니다. 지원되는 환경에서 업데이트 후 상태 확인을 합니다. 설치 권한 해제는 설치 서버의 권한 사용을 끝내는 동작이며 학생 기록 삭제가 아닙니다. 문제 해결을 위해 보안 기능을 끄지 않습니다.
